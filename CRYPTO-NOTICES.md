# PSP format and cryptography research credits

The PXP2 emulator CPU and Android frontend do not incorporate a PPSSPP engine or native library. The firmware work uses published PSP format research and cryptographic constants, and a Java adaptation of independent KL compression research. These components must not be described as wholly invented by PXP2.

- `FirmwareCrypto.java`, `FirmwareKeys.java`, and `PsarArchive.java`: Java implementation informed by PSARDumper and KIRK format research, including the work of PspPet, Nem, Dark_AleX, Noobz, Team C+D, M33, bbtgp, Proxima, some1, Draan, coyotebean, Davee, hitchhikr, kgsws, liquidzigong, Mathieulh and SilverSpring. Reference distribution: https://github.com/cielavenir/psardumper-pc . Constants are published PSP interoperability data. No C crypto engine, AES implementation, or PPSSPP code is linked. Platform Java cryptography provides AES, DES and SHA. CMAC follows RFC 4493.
- `KlDecoder.java`: bounded Java adaptation of KL3E/KL4E decoding reverse engineered by artart78 from the PSP firmware's UtilsForKernel_6C6887EE routine, with acknowledgments to BenHur and tpunix. Reference: https://github.com/cielavenir/psardumper-pc/blob/master/kl4e.c . Preserve this attribution. Distributed under GPL version 3 or later with the accompanying license text.
- `PrxLoader.java`: implementation informed by the PSP module binary format, PSPDEV PRXTool by TyRaNiD and uOFW's reverse engineering of `sceKernelApplyPspRelSegment2`. Source references: https://github.com/pspdev/prxtool and https://github.com/uofw/uofw . The reference sources are not build dependencies.
- `Atrac3plusTables.java`: ATRAC3plus format constants, as data only: Huffman code-length counts and symbol tables, word-length and scale-factor shapes and weights, spectrum code-table descriptors, scale-factor and mantissa tables, the power-compensation noise table and the inverse PQF prototype coefficients. Taken from FFmpeg's `libavcodec/atrac3plus_data.h` and `atrac3plusdsp.c`, Copyright (c) 2010-2013 Maxim Poliakovski (ATRAC3plus reverse engineering, with thanks to Benjamin Larsson and Michael Karcher). FFmpeg is licensed under LGPL-2.1-or-later; these values are used under its option to convert to the GPL, as part of PXP2 (GPL-3.0). Source: https://github.com/FFmpeg/FFmpeg/tree/master/libavcodec . The decoder itself (`Atrac3plus.java`) is PXP2's own Java implementation of the format. No FFmpeg code is linked or copied, and FFmpeg is used only as the reference decoder in `core/tests/Atrac3plusTest.java`.
